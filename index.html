Sedang dipelajari

01

MikroTik

Routing, firewall, NAT, dan hotspot. Mengatur lalu lintas jaringan supaya klien bisa menjangkau server ini.

02

Linux

Debian/Ubuntu di sisi server: user, permission, service systemd, dan script bash untuk telemetri.

03

Web Server

Nginx / Apache sebagai penyaji halaman. Virtual host, port binding, dan serving static files.

Kenapa halaman ini ada

Sederhana: untuk membuktikan rantai dari jaringan sampai browser sudah jalan. Paket melewati MikroTik, diterima Linux, disajikan Web Server, lalu berakhir di layar Anda. Data di atas dibaca langsung dari mesin.
